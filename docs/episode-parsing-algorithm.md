# 季 / 集识别算法（v1 草案，2026-11-24）

> 只解决两件事：**这个文件属于哪一季**、**它是第几集**。两者都确定后才谈统计与转存。

## 0. 输入与归一化

- 输入：文件节点（文件名 + 所在目录链，最多到剧名根）、任务季设置（`0 / 1..99 / -1 / -2`）、TMDB 该季总集数
- 归一化：去扩展名、全角转半角、统一大小写比较、去掉常见站点后缀（`[xx站]`、`www.xxx.com`）

## 1. 季号识别（优先级从高到低）

| 级别 | 证据 | 例子 | 结果 |
| --- | --- | --- | --- |
| S1 | 文件名里的 `SxxExx` | `剧名.S02E05.2160p.mkv` | 季=2（同时得到集=5） |
| S2 | 文件名独立季标记 | `S02.mp4`、`Season 2 EP05`、`第2季 05`、`第二季 05` | 季=2 |
| S3 | 目录链季标记（离文件最近的一层优先） | `Season 2/`、`S02/`、`第2季/`、`第二季/`、`第二部/` | 季=2 |
| S4 | 特别篇标记 | `Specials/`、`SP/`、`特别篇/`、`OVA/`、`S00/` | 季=0 |
| S5 | 任务设定 | 任务选了「第 2 季」且来源锁定 `Season 2` 目录 | 季=2（作为**范围**，不是证据） |
| S6 | 都没有 | 平铺分享 | 季=`FLAT`（不建季目录） |

**关键区分**：S5 是「范围」不是「证据」。任务选了第 2 季，含义是「只接受第 2 季的文件」，而不是「把所有文件都当成第 2 季」。

**冲突规则**（这是「指定季为什么还会乱」的根）：

1. 文件季与目录季都明确且相同 → 采用
2. 两者不同 → **以文件名季为准**（上传者乱起目录名是常态），但记一条「季冲突」提示
3. 文件名/目录季落在任务范围之外 → **该文件不转存**（越界），计入「越界 N 个」
4. 任务范围锁定某季目录、文件本身无季证据 → 采用任务季（目录就是证据）
5. 任务范围锁定某季目录、文件季证据与之矛盾 → 不转存（不确定，宁可不转）

## 2. 集号识别（优先级从高到低）

| 级别 | 规则 | 例子 | 说明 |
| --- | --- | --- | --- |
| E1 | `SxxExx` | `S02E05`、`S02.E05`、`S02_EP5` | 最强，季集同时拿到 |
| E2 | 中文集数 | `第5集`、`第5话`、`第5回`、`第5期` | 含 `第12話` 繁体 |
| E3 | 英文集标 | `E05`、`EP05`、`Ep.5`、`Episode 5` | 需前面不是字母，避免误吃 `SE05` 里的 E |
| E4 | 末尾/独立数字 | `剧名 05.mp4`、`[组] 剧名 - 05 [1080p].mkv` | 本次**新增**，原来只认开头 |
| E5 | 开头数字 | `219-4K.mp4`、`05.mp4` | 现有规则，保留 |
| E6 | 跨文件序列推断 | 见第 3 节 | 只在 E1~E3 全无时才启用 |
| — | 无 | `合集.mp4`、`预告.mp4` | 未命中，不转存 |

**数字黑名单**（在任何一级都不当集号）：年份 `1900–2099`、分辨率 `480/576/720/1080/1440/2160/4320` 及其后跟 `p/P/i/I`、编码 `264/265/AV1/HEVC`、`10bit/8bit`、`HDR10`、音轨 `2.0/5.1/7.1`、`Sxx` 已用作季号的数字、TMDB id、文件体积数字、`x264/x265`。

**多数字消歧**（文件名有 2 个以上数字时）：

1. 有 E1~E3 强标记 → 直接用，其余数字忽略（`S02E05.1080p` 里的 02/05/1080 不会打乱）
2. 无强标记 → 排除黑名单后，按证据加权打分：
   - `末尾数字` +2（资源站最常用 `剧名 - 05`）
   - `前后被分隔符包裹`（` - `、`[]`、`()`）+1
   - `值在 1..该季总集数` +2，`在 1..999` +1
   - `等于剧名里的年份` −3（`凡人修仙传 2020 05` 里的 2020 不该是集）
3. 仍并列 → 记为「歧义」，该文件**不转存**（宁可少转，不误转）

## 3. 跨文件序列推断（用户提的「哪个数字在变」）

**只在 E1~E3 全部缺失、且目录内有 ≥5 个文件时启用**，避免小样本误判。

对每个「数字位置」（开头数字 / 末尾数字 / 每个括号内数字）分别统计：

| 指标 | 含义 | 采用阈值 |
| --- | --- | --- |
| 唯一率 | 该位置取值互不相同的比例 | = 100%（数值重复 → 那是分辨率/年份，不是集号） |
| 连续率 | 排序后相邻差值 = 1 的比例 | ≥ 70% |
| 覆盖数 | 不同取值个数 | ≥ 5 |
| 范围 | 最小/最大 | 落在 `1..max(999, 总集数)` |

满足则**整批采用该位置为集号**；不满足则整批 UNMATCHED，不转存。

这样 `1080p`（每个文件都重复）、`2020`（年份重复）会被唯一率直接淘汰，只有真正递增的数字会被选中。

## 4. 季与集的联立

1. E1 命中 → 季集都来自文件名，直接定案
2. 季来自 S2/S3，集来自 E2~E5 → 组合成 `(季, 集)`
3. 季来自 S5（任务范围）、集有编号 → 定案
4. 集来自 E6 推断 → 必须同时有明确季（S1~S3 或 S5），否则不转
5. 特别篇：`S1S4`（专指季节=0）或文件名 `SP01/特别篇 第3话` → 季=0、集=编号 → 目标 `剧名/Season 0/`
6. 剧场版关键词 + 无编号 → `MOVIE`，不转、不计数
7. 集号越界（`<1` 或 `>该季总集数`）→ 不转，计「越界 N 个」

## 5. 输出与后续

每个文件输出三选一：

- `Target(season, episode, isSpecial)` → 进入「先算名 → 转存 → 改名 → 失败回滚」流程
- `Skip(reason)` → 未命中 / 剧场版 / 越界 / 噪声
- `Ambiguous(reason)` → 歧义，不转并提示

命名沿用现有规则：`剧名.SxxExx`，特别篇为 `剧名.S00E01`；多季按判定出的季分目录。

统计（下一步再做，不在本算法内）：只对 `Target` 集合按季分区计数，`transferred == renamed`。

## 6. 流程总览（伪代码）

```
for file in scanTree:
    if noise(file): Skip(NOISE); continue
    s = seasonOf(file)          # S1→S2→S3→S4，返回 (season, evidence)
    e = episodeOf(file)         # E1→E2→E3→E4→E5
    if s == null: s = taskSeasonRange(file.dir)   # S5
    if e == null: pendingSequence.add(file)        # 待 E6
    if movieKeyword(file) and e == null: Skip(MOVIE); continue
    if s.outOfRange(task): Skip(OUT_OF_RANGE); continue
    decide(s, e); if ambiguous: Skip(AMBIGUOUS)

runSequenceInference(pendingSequence)   # 第 3 节阈值，命中的补上 e
```
