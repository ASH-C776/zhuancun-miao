> 本文档是全项目 UI 的唯一口径。后续任何页面改动先对照本文档，不合规先改代码再提交。
> 现状审计基于 `app/src/main/java/com/ashchan/cloudsaver/ui/` 下的 8 个界面的实际代码。

## 一、现状审计（问题清单，带实测数据）

| # | 问题 | 证据 | 影响 |

## 二、规范条款

### 1. 布局骨架

- 所有页面统一 `Scaffold`：`TopAppBar` + 内容区，**内容区自己处理系统栏内边距**（`WindowInsets.safeDrawing`），底色铺满整屏（含状态栏与小白条后面）。
- 全屏弹层（保存位置、TMDB 搜索这类）**不再用独立 `Dialog` 窗口**，一律做成同窗口覆盖层：`Surface(fillMaxSize)` 铺底 + 正文让开系统栏 + `BackHandler` 接管返回。

### 2. 顶栏（TopAppBar）

| 元素 | 规范 |
|---|---|
| 高度 | 56dp（不自定义） |
| 返回 | **统一 `ArrowBack` 图标**，热区 48dp；禁止再出现文字「返回」 |
| 标题 | `titleMedium`（20sp）+ `SemiBold`，左对齐 |
| 右侧动作 | **最多 2 个**；只放「低频 / 不可挪」的动作（见第 3 条） |
| 底色 | `colorScheme.surface`，无阴影 |

### 3. 单手操作（核心规则）

**拇指可达区**：屏幕**底部 40%**（约 y > 1440px / 2400px）+ 右侧边缘 60% 区域。所有**高频**操作必须落在这个区域或卡片本体内。

| 频次 | 操作示例 | 允许位置 |
|---|---|---|
| 高频（每次打开都用） | 刷新单个任务、新增任务、保存任务、运行一次 | 卡片内图标 / 右下 FAB / 底部操作条 |
| 中频 | 全部刷新、运行日志 | 顶栏可留，但必须**同时**有低区入口（如日志页从右下 FAB 长按进入） |
| 低频（设置一次就不动） | 设置、关于、打赏、主题 | 顶栏或二级页内，可留顶部 |

据此的落位结论：

- **主页**：顶栏只保留「返回」位（首页没有返回，即空）→ 把「刷新 / 日志 / 设置」迁到**右下角**：`FAB（+ 新增）` 为主，其上纵向排「刷新」「日志」「设置」三个小按钮，或在 FAB 长按弹出三者菜单。首选前者（一眼可见，不用记长按）。
- **新建/编辑页**：「保存」迁到**右下角主按钮**（文字按钮，宽 88dp）；「运行一次」放它左侧一个图标按钮。顶栏只留返回。
- **日志页**：「清除」保留顶栏（低频，且是破坏性操作，放远一点反而安全）。
- **设置页**：全部内容靠滚动，无需特殊处理。

### 4. 图标

- **只用 Material core 的 11 个**：`Add / ArrowBack / Check / DateRange / Delete / Home / List / PlayArrow / Refresh / Search / Settings`。不够表达就用文字，不引 `material-icons-extended`（apk 会大 1–2MB）。
- **尺寸三档锁死**：

| 档位 | 尺寸 | 用在哪 |
|---|---|---|
| 微 | 16dp | 与文字并排的状态标记（登录状态对勾、按钮内的小图标、提示条图标） |
| 内联 | 20dp | 行内小图标（设置行左侧、卡片底部刷新按钮内的图标、进度指示器） |
| 标准 | 24dp | 顶栏动作、底部胶囊四键图标 |
| 大 | 32dp | 空状态居中图标（任务空态 / 日志空态 / 记录空态） |

- 与图标无关的尺寸只用于触控热区：48dp（所有 IconButton / 列表行最小热区）。

- **禁止 emoji 当图标**（现存 `📁` 一处，改成 `Home` 或纯文字）。`▶ / 🔒 / ⚠` 这类只在文案里当符号用，不作图标。
- 每个图标必须有 `contentDescription`（无障碍），装饰性图标置 `null`。

### 5. 字号阶梯（5 档，不许出现第 6 种 sp）

| 级别 | sp | 用在哪 | 权重 |
|---|---|---|---|
| `labelLarge` | 14 | 分区标题（「保存位置」「更新日」） | Medium |
| `bodySmall` | 12 | 卡片元信息（周几·网盘·时间）、辅助说明、运行日志正文 | Normal |
| `bodyMedium` | 14 | 正文、列表项、输入框内文字 | Normal |
| `titleSmall` | 16 | 卡片剧名、列表主标题 | SemiBold |
| `titleMedium` | 20 | 页面标题、区块大标题 | SemiBold |

规则：
- 同一行内**最多两种字号**，且必须是一大一小（标题 + 辅助），禁止三者并列。
- 强调只用 `SemiBold`，**不用 Bold/Black**（中文在手机上会糊）。
- 弱化信息只用 `onSurfaceVariant` 颜色降级，**不再额外缩小字号**（现在存在「又小又灰」的双重降级）。

### 6. 间距与圆角

- 间距只用 **4 / 8 / 12 / 16 / 24** 五档（现有 6、10、14、20 逐步并入相邻档）。
  - 4：图标与文字之间
  - 8：同一组内的行间
  - 12：卡片内容内边距（上下）、列表项左右
  - 16：区块之间、页面左右边距
  - 24：页面顶部/底部大留白
- 圆角：卡片 **16**、chip/小按钮 **12**、对话框 **24**、进度条 **2**。

### 7. 色彩语义

| 用途 | 取值 |
|---|---|
| 主操作 | `primary`（暖橘） |
| 成功 / 收齐 | `SuccessGreen` |
| 缺集 / 需注意 | 现有 `TaskColors.behind()`（浅色 `#B26A00` / 深色 `#E0A94F`） |
| 错误 | `colorScheme.error` |
| 弱化信息 | `onSurfaceVariant` |
| 分隔线 | `outlineVariant` |

约束：状态色**只出现在徽标、进度条、错误文案**三处，不染标题、不染卡片底色。

### 8. 触控

- 任何可点元素**最小 48×48dp** 热区（`SmallChoice`、`FilterChip` 需补 `heightIn(min = 48.dp)` 或加外padding）。
- 列表行最小高度 48dp；卡片整块可点（`combinedClickable`），刷新图标单独可点且不触发卡片点击。
- 破坏性操作（删除、清空）**必须二次确认**，且确认弹窗里把「影响范围」写清（如「任务和集数进度不受影响」）。

### 9. 文案

- 按钮：**≤4 字**动词（保存 / 选这里 / 清除 / 取消）。
- 不写解释性小字（已执行：TMDB 区块的说明段已删）；确需说明时，写成一句 `bodySmall`，最多一行。
- 空状态：一句标题 + 一句操作指引，不超过两行。

### 10. 逐页规范

| 页面 | 顶栏 | 主操作位置 | 关键约束 |
|---|---|---|---|
| 主页 TASKS | 标题「转存喵」，无返回 | 右下：FAB「+」、其上「刷新 / 日志 / 设置」 | 卡片三行结构不变（剧名+徽标 / E→E+时间 / 刷新+周几·网盘·自动） |
| 新建·编辑 NEW_TASK | 返回 + 标题 | 右下「保存」+ 左侧「运行一次」图标 | 一屏可见，字段顺序：名称→链接→保存位置→季度→命名规则→更新日→播出时刻 |
| 运行日志 RUNLOG | 返回 + 标题 + 清除 | — | 清除放顶栏（低频+破坏性，远离拇指） |
| 保存位置选择 | 覆盖层自带「返回」 | 无（返回即保存，面包屑右侧提示） | 面包屑可点、切盘重置目录、沉浸式 |
| 设置 SETTINGS | 返回 + 标题 | — | 分区顺序：网盘账号 → TMDB → 外观 → 关于/打赏 |
| 记录 HISTORY | 返回 + 标题 | — | — |
| 关于 ABOUT / 打赏 DONATE | 返回 + 标题 | — | — |

**完成动作已从顶部移除（Stage 20 修订）**：全屏选择器不再放「选这里」。**左上返回 = 选中当前目录**，系统手势返回同理；如果打开后既没切网盘也没下钻目录就返回，则视为「只是看看」，保持原选择。面包屑行右侧常驻主色小字「返回即保存」作为提示。此规则优先于原先「选这里允许留在顶部」的例外。
